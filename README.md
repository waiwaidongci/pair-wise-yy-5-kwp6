# 手工织锦纹样排版台

直接打开 `index.html` 使用。支持网格绘制、色线统计、撤销重做和导出 JSON。

## 可追版本的工作区

排版台现在分为「工作稿」和「已提交版本」两部分：

- **提交打样**：填写名称和备注后点「提交打样」，当前的网格、色线用量、备注会被深拷贝并
  冻结成一个版本，自动分配递增序号（第 1 版、第 2 版……）。提交后工作稿仍可随意编辑，
  改动不会影响任何已提交内容。
- **重名拒绝**：已存在的版本名称不能再次提交，界面会说明原因，要求改名后再提交。
- **从旧版本开始**：在版本卡片上点「从此版开始」，会把该版的网格复制成一份新的工作稿
  （并记录来源版本），旧版本本身保持不变；改完再提交即为下一版。
- **查看冻结稿**：点「查看冻结稿」可只读查看任意版本的网格与提交时的色线用量快照。
- 版本顺序、每版用量快照、备注、来源关系随工作区自动存入浏览器本地存储；
  首次打开时会自动把旧版单稿（`zfl31Pattern`）迁为工作稿。

## 文件结构

| 文件 | 职责 |
| --- | --- |
| `js/archive.js` | 存档：本地持久化、旧稿迁移、JSON 导出 |
| `js/workspace.js` | 状态管理：工作稿编辑、提交冻结、版本回溯、撤销重做 |
| `js/ui.js` | 界面交互：渲染、事件、版本列表与只读预览 |
